# Legal Nexus

Source migration from the existing Legal Nexus Vercel production deployment.

The available application source is preserved under `src/src/`. Configure the Vercel project root directory as `src/src` when linking this repository.

This import contains the source files exposed by the production deployment. It may not include local-only files, ignored files, assets, or migration history that were not part of that deployment. Do not commit secrets or production environment values; configure Supabase environment variables separately in Vercel.
