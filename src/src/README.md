# Legal Nexus

The operating system for corporate legal departments.

## Foundation
- Next.js App Router + TypeScript
- Supabase PostgreSQL foundation (separate project)
- Organization-aware data model and row-level security
- Initial domains: corporate entities, departments, legal matters, contracts, administrative investigations, documents and audit events.

## Development
```bash
npm install
npm run dev
```

This is the initial interface foundation. Authentication, organization onboarding, role-based authorization, storage policies and business workflows are not yet connected.
